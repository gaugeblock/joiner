# Changelog

All notable changes to `joiner` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0-beta.2] - 2026-10-24

### Added
- `joiner-core`: support unified `.gaugeblock/spool/` directory resolution for synthesis traces (GB-36).
- `joiner-core`: integrate `storypole` compiler verification and Git tracking fields in `VerificationReceipt` (GB-26, GB-28).

## [0.1.0-beta.1] - 2026-10-22

### Added
- `joiner-core`: System 1 classification router mapping `(TaskNode + LexicalScope)` to deterministic `dado` patterns, AST surgical edits, or Oracle escalation.
- `joiner-core`: hole filler orchestrator executing `batten`-constrained token completions through `sawhorse` (`ModelRole::HoleFiller`).
- `joiner-core`: compiler verification loop passing exact `miter` diagnostics and compiler exit codes back into progressive retry loops.
- `joiner-core`: Oracle fallback handler tagging novel code solutions for downstream `rabbet` pattern mining.
- `joiner-core`: local synthesis telemetry logger writing `AnonymizedSynthesisTrace` records (Bronze, Silver, Gold tiers).
- `joiner-cli`: subcommands `joiner run-next`, `joiner synthesize`, and Axum daemon.
- `joiner-mcp`: stdio JSON-RPC 2.0 Model Context Protocol server exposing `joiner_run_next`, `joiner_synthesize`.

## [0.0.1-alpha.1] - 2026-10-21

### Added
- Initial namespace reservation on crates.io and GitHub repository scaffold.
